# AI for Healthcare Administration — Beginner Manual

A step-by-step, printable beginner manual on using AI for healthcare
administration tasks: forms, scheduling, billing basics, compliance reminders,
and documentation workflows. Includes a static HTML site you can open in any
browser or print from.

Created by **Asdale Dynamics, LLC** — Indiana, formed October 2026. Asdale
Dynamics publishes beginner-friendly AI education, books and guides, and
practical tools. This guide is part of the same plain-English, step-by-step
style as Dylan Asdale's *The Massive AI Manual* and the hub site
dylanasdale.github.io: AI explained "like a friend would," never condescending,
always tested, local-first where possible.

## Who this is for

Healthcare administrators, front-desk staff, practice managers, nurses, and
other clinic staff who want to use AI tools to reduce paperwork and keep the
office running smoothly. No technical background required.

## What's inside

- `docs/` — Markdown chapters of the beginner manual
- `site/` — Static HTML version of the same manual (open any `.html` file in a browser)
- `docs/checklists/` — Printable, step-by-step admin checklists

## Important: education only

This manual is **education only**. It is not medical advice, not legal advice,
and not medical billing or coding advice. It does not create a
provider-patient relationship, and it does not replace your clinic's
compliance officer, attorney, or certified medical coder.

**Never paste patient data — including names, dates of birth, insurance IDs,
or any other identifying information — into a public AI tool.** Treat anything
you type into an AI tool as if it could be read by others.

Always check with your clinic's compliance officer, legal counsel, or a
certified billing professional before changing forms, billing workflows, or
documentation practices.

## How to use

1. Start with `docs/00-read-first.md` (or `site/index.html`) for the ground rules.
2. Read the chapters that match your work: forms, scheduling, billing,
   compliance, or documentation.
3. Print the checklists in `docs/checklists/` and work through them step by
   step at your desk.
4. Each chapter ends with a "Try this today" step so you can start small.
